 # 设计说明 (Design Document)
 
 ## 1. 页面区块与浏览顺序
 
 单页式设计，按以下顺序从上到下排列：
 
 1. **Hero（站点标题）** — 站点名称、一句话定位、GitHub 行动入口
 2. **About（关于本站）** — 站点定位、目标用户与使命说明
 3. **Skills（课程分类）** — 按领域展示课程类别（计算机、AI、金融科技等）
 4. **Projects（课程列表）** — 具体课程资料条目卡片
 5. **Contact（联系方式）** — GitHub 主页链接
 
 顶部有粘性导航栏，可点击跳转到对应区块。
 
 ---
 
 ## 2. 颜色、字体与整体风格
 
 | 设计维度 | 方案 |
 |----------|------|
 | 整体风格 | 简洁、清爽、信息导向，利于快速浏览课程列表 |
 | 主色调 | 基于 Modern Resume Theme 默认蓝色系 (#4a90d9) |
 | 字体 | 无衬线字体：系统默认 + Noto Sans SC / PingFang SC 中文优化 |
 | 字号层级 | H1 > H2 > 正文 > 辅助文字，保持清晰层级 |
 | 间距 | 区块间留白充足，课程卡片紧凑但不拥挤 |
 
 ---
 
 ## 3. 桌面端和移动端要求
 
 ### 桌面端（宽度 ≥ 1024px）
 - Skills 区域用网格布局展示课程分类
 - Projects 区域用卡片列表，课程信息水平排列
 - 内容区域最大宽度 960-1200px，居中显示
 
 ### 移动端（宽度 < 768px）
 - 单栏布局，所有区块纵向堆叠
 - 导航折叠为汉堡菜单
 - 课程卡片元信息（平台、时间、状态）纵向排列
 - 图片自适应宽度，无横向滚动
 - 按钮/链接触摸面积 ≥ 44px

 | 文件 | 职责 |

 | `index.md` | 首页：使用 home 布局，包含 About 内容 |

 | `README.md` | 项目说明 |
 | `docs/prd.md` | 产品需求文档 |
 | `docs/design.md` | 设计说明（本文） |
 | `docs/checklist.md` | 验收清单 |
 | `report/final-report.md` | 最终报告 |
 | `screenshots/` | 截图证据 |
