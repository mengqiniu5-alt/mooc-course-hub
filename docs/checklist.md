 # 验收清单 (Checklist)
 
 > MOOC 课程资料站 — 每一项都是能看见、能点击或能复现的检查。
 
 ---
 
 ## 六项硬性门槛
 
 - [ ] G1：GitHub Pages 链接可在无痕窗口打开，无 404、无需登录
 - [ ] G2：Hero / About / Skills / Projects / Contact 五区块齐全，内容真实
 - [ ] G3：docs/prd.md、docs/design.md、docs/checklist.md 存在、非空且与网站一致
 - [ ] G4：个人 GitHub 仓库至少有 3 次有意义 Commit
 - [ ] G5：report/final-report.md 完整，screenshots/ 至少 4 张截图
 - [ ] G6：TA-Claw 预览无误，完成二次确认，看到 "Submitted successfully"
 
 ---
 
 ## 内容检查
 
 - [ ] Hero 区：站点名称 "MOOC 课程资料站" 显示正确，定位清晰
 - [ ] About 区：说明站点定位与目标用户，无模板占位
 - [ ] Skills 区：至少 5 个课程分类，名称与实际内容对应
 - [ ] Projects 区：至少 4 门课程资料条目，信息真实
 - [ ] Contact 区：GitHub 主页链接有效
 - [ ] 无模板作者名、示例项目和虚构内容
 
 ---
 
 ## 功能检查
 
 - [ ] 导航栏链接均能正确跳转
 - [ ] 课程卡片中的 MOOC 平台链接可打开
 - [ ] GitHub 链接有效
 - [ ] 无死链和点击无反应的按钮
 
 ---
 
 ## 桌面端 & 移动端显示
 
 - [ ] 桌面端（≥1024px）：布局完整，无溢出或遮挡
 - [ ] 移动端（<768px）：单栏显示，无横向滚动
 - [ ] 中文文字无乱码或重叠
 - [ ] 课程卡片在手机端元信息排列整齐
 
 ---
 
 ## 工程检查
 
 - [ ] README.md 已写明模板来源、主要修改和 Pages 链接
 - [ ] _config.yml 配置正确（remote_theme、插件、区块开关）
 - [ ] docs/ 三份文档完整
 - [ ] report/final-report.md 已完成
 - [ ] screenshots/ 至少有 4 张截图
 - [ ] 至少 3 次有意义 Commit
 - [ ] 无 .env、密码、API Key、Token 等隐私文件
 - [ ] 无依赖目录、构建产物和无关大文件
 
 ---
 
 ## 线上发布
 
 - [ ] Pages 地址可访问，内容与最终 Commit 一致
 - [ ] 无痕窗口验证通过
 - [ ] README.md 和 report/final-report.md 均已记录 Pages 链接
 
 ---
 
 ## TA-Claw 提交
 
 - [ ] 预览确认代码树、报告、截图齐全
 - [ ] 匹配会话属于本项目
 - [ ] 已完成二次确认
 - [ ] 看到 "Submitted successfully"
