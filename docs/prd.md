 # 产品需求文档 (PRD)
 
 ## 项目概述
 
 | 项目 | 内容 |
 |------|------|
 | 项目名称 | 牛萌琪 个人主页 |
 | 作业性质 | OPC-AI 培训营模块三实验课 · 个人基础作业 |
 | 目标平台 | GitHub Pages（桌面端 + 移动端浏览器） |
 | 开发方式 | 规范化 AI 开发流程（Vibe → Spec → Harness → GitHub → Pages → TA-Claw） |
 | 基础模板 | Modern Resume Theme (sproogen/modern-resume-theme) |
 
 ---
 
 ## 1. 目标访问者是谁？他们最先寻找什么信息？
 
 **目标访问者：**
 - 课程教师与助教（作业验收方）
 - 未来实习或求职单位（展示个人能力与项目经验）
 - 同学与同行（交流与互相了解）
 
 **最先寻找的信息：**
 - 我是谁（姓名、学校、专业方向）
 - 我具备什么能力
 - 我做过哪些项目
 - 如何联系我
 
 ---
 
 ## 2. 希望访问者看完后记住什么？
 
 - 牛萌琪是一个善于合作谈判、对产品方向有浓厚兴趣的信息管理专业学生
 - 能够独立完成从需求分析到方案交付的完整项目流程
 - 在金融科技反欺诈领域有实际的项目实践经验
 
 ---
 
 ## 3. 本期必须包含哪些内容？
 
 - **Hero 区**：姓名 + 学校专业 + 一句话定位 + 行动入口
 - **About 区**：真实个人简介
 - **Skills 区**：合作谈判、产品思维、需求分析、AI 工具应用等真实能力
 - **Projects 区**：明川银行 AI 反欺诈预警系统（实验1+实验2）+ 本网站项目
 - **Contact 区**：GitHub 主页链接
 - **文档**：README.md、docs/prd.md、docs/design.md、docs/checklist.md
 - **报告与截图**：report/final-report.md + screenshots/ 至少 4 张截图
 - **Git 要求**：至少 3 次有意义 Commit + Pages 正式链接
 - **TA-Claw 提交**：预览 + 二次确认 + 成功回执
 
 ---
 
 ## 4. 本期明确不做什么？
 
 - 不从零编写全部 HTML/CSS/JavaScript
 - 不加入登录、数据库、支付、复杂后台
 - 不虚构项目经历和技能
 - 不公开私人手机号、住址、身份证件
 - 不包含课程邀请码、密码、API Key 等隐私数据
 
 ---
 
 ## 5. 怎样判断网站完成？
 
 | 编号 | 门槛 | 通过标准 |
 |------|------|----------|
 | G1 | 作品可访问 | Pages 链接可在无痕窗口打开 |
 | G2 | 内容属于本人 | 五区块齐全，内容真实，无模板占位 |
 | G3 | 规格文件完整 | PRD/Design/Checklist 存在且与网站一致 |
 | G4 | 过程可追溯 | 个人仓库至少 3 次有意义 Commit |
 | G5 | 证据可复核 | 报告完整 + 至少 4 张截图 |
 | G6 | 平台确已收件 | TA-Claw 二次确认 + 成功回执 |
