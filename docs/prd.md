 # 产品需求文档 (PRD)
 
 ## 项目概述
 
 | 项目 | 内容 |
 |------|------|
 | 项目名称 | 优课资料站 — UOOC 课程备考资料索引 |
 | 作业性质 | OPC-AI 培训营模块三实验课 · 个人基础作业 |
 | 目标平台 | GitHub Pages（桌面端 + 移动端浏览器） |
 | 开发方式 | 规范化 AI 开发流程（Vibe → Spec → Harness → GitHub → Pages → TA-Claw） |
 | 基础模板 | Modern Resume Theme (sproogen/modern-resume-theme) |
 
 ---
 
 ## 1. 目标访问者是谁？他们最先寻找什么信息？
 
 **目标访问者：**
 - 选修优课联盟 (UOOC) 课程的大学生（主体用户）
 - 需要为开卷考试下载课件资料进行备考的学生
 - 课程教师与助教（作业验收方）
 
 **最先寻找的信息：**
 - 我选的课在这个站上有资料吗？
 - 资料在哪里下载？文件格式是什么？
 - 资料是什么时候更新的，版本是否最新？
 
 ---
 
 ## 2. 希望访问者看完后记住什么？
 
 - 这是一个专注于 **优课联盟 (UOOC)** 课程的资料索引站
 - 开卷考试前可以来这里一站式获取课件，不用在各平台逐个翻找
 - 每份资料由选课同学提供，真实有效
 - 站点的价值是**减少信息搜集成本**
 
 ---
 
 ## 3. 本期必须包含哪些内容？
 
 **五个基础区块：**
 - **Hero 区**：站点名称 + 一句话定位（"优课联盟备考资料·一站式索引"）
 - **About 区**：站点定位、目标用户与使命说明
 - **Skills 区**：课程分类（人文社科、计算机、金融科技等）
 - **Projects 区**：具体课程资料条目（课程名、简介、文件列表、下载链接）
 - **Contact 区**：GitHub 主页链接
 
 **资料存储结构：**
 ```
 assets/course-materials/课程名/
 ├── 课件1.pdf
 ├── 复习提纲.pdf
 └── ...
 ```
 资料由用户提供，通过 Git 提交上传，不做爬取。
 
 **文档要求：**
 - README.md、docs/prd.md、docs/design.md、docs/checklist.md
 - report/final-report.md + screenshots/ 至少 4 张截图
 
 **Git 与提交要求：**
 - 个人 GitHub 仓库至少 3 次有意义 Commit
 - GitHub Pages 正式链接
 - TA-Claw 预览 + 二次确认 + 成功回执
 
 ---
 
 ## 4. 本期明确不做什么？
 
 - 不从零编写全部 HTML/CSS/JavaScript
 - 不加入登录、数据库、支付、复杂后台或访客追踪
 - **不做自动爬取**：所有资料由选课同学主动提供，网站仅做整理和索引
 - **不涉及盗版分发**：资料是优课联盟开卷考试备考用途，学生有权访问和下载
 - 不托管课程视频（仅索引课件 PDF 等文档）
 - 不公开私人手机号、家庭住址、身份证件或其他敏感信息
 - 不包含课程邀请码、密码、API Key、Token、.env 等隐私数据
 
 ---
 
 ## 5. 怎样判断网站完成？
 
 以下六项硬性门槛全部通过即视为完成：
 
 | 编号 | 门槛 | 通过标准 |
 |------|------|----------|
 | G1 | 作品可访问 | Pages 链接可在无痕窗口打开 |
 | G2 | 内容属于本人 | 五区块齐全，内容真实，无模板占位 |
 | G3 | 规格文件完整 | PRD/Design/Checklist 存在且与网站一致 |
 | G4 | 过程可追溯 | 个人仓库至少 3 次有意义 Commit |
 | G5 | 证据可复核 | 报告完整 + 至少 4 张截图 |
 | G6 | 平台确已收件 | TA-Claw 二次确认 + 成功回执 |
 
 ---
 
 ## 6. 哪些信息不能公开？
 
 - 课程邀请码、作业代码
 - 个人密码与登录凭据
 - API Key、Token、.env 文件
 - 私人手机号、家庭住址、身份证件号码
 - 教师/助教的个人反馈内容
